# bro is literally a smart tv

### Q: What is this?
A: Python app that turns my raspberry pi into a smart TV.

### Q: Why?
A: Sometimes I wonder the same thing.
Short story long, my flatmates and I have an awkward projector setup that's tricky to plug stuff into to launch up netflix or whatever, so I decided to put my dusty pi to use.
Younger me thought this would be a simple endeavour, that would only take a month or so to set up and get working, but my initial mental calculations have served me ill, and
things have proven to be trickier than I thought they would be. As a result I have now spent years very slowly working on this project, and by the time it's done we'll have probably
moved out. HOWEVER I've had so much fun and learned a lot from working on it, so I'll probably just finish it at some point for the lives laughs and loves because the real question is:
why not?

### Q: What am I supposed to do with this?
A: Nothing (lol). This was never developed as something that other people can use (also the project is not yet finished), it's created to be very particularly suited to my specific
projector setup, as I never thought that anyone else would ever take an interest in this repo. However, times and I have changed, and I now would like to be employed, and
apparently having a lovely project to showcase to the world counts towards big bonus points for recruiters (hi by the way, I hope you liked my CV), so I've made the repo public
to prove to everyone that I can actually write code 😭😭
